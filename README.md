# GeoRomb — список лицензий

`revoked.json` — подписанный список активаций. Приложение скачивает его по адресу
https://bakhtiyararzimetov.github.io/GeoRomb/revoked.json и само проверяет подпись.

## Как выдать или продлить доступ

1. Откройте вкладку **Actions** этого репозитория.
2. Слева выберите шаблон: **1. Активация на 7 дней**, **2. Активация на 30 дней**, **3. Активация на 365 дней**
   или **4. Отозвать лицензию**.
3. Нажмите **Run workflow**, вставьте ID устройства (до 20 штук через пробел или запятую) → **Run workflow**.
4. Через минуту в запуске появится таблица: ID и до какого числа действует. Клиенту — нажать «Проверить» в приложении.

Если ID уже активен, срок продлевается от его конца. Бессрочные активации не укорачиваются.

## Ключ

Подпись делается закрытым ключом из секрета **GEOROMB_PRIVATE_KEY**
(Settings → Secrets and variables → Actions). В файлы репозитория и в логи ключ не попадает.
Без этого секрета шаблоны не работают.
